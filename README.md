# Movilidad Urbana NYC

## Título
Análisis geoespacial y temporal de transporte en la ciudad de Nueva York.

## Caso elegido
Caso 04 · Movilidad Urbana Nueva York

## Integrantes
- Maria de Lourdes Ponce Ochoa
- Nathaly Noelia Paredes
- Aaron Sebastian Spin

## Descripción
Este proyecto tiene como objetivo identificar los "Hot spots" (puntos calientes) de mayor demanda de transporte en la ciudad de Nueva York. Adicionalmente, analizamos cómo varía esta actividad a lo largo del día y de la semana, apoyándonos en visualizaciones cartográficas.
